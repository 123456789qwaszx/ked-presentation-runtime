## 2. 수동 세이브 (StageState)

VN은 RPG의 체크포인트와 달리 **특정 대사 시점에 저장**을 원한다. 지금의 장면 경계 세이브(자동)는
건드리지 않고, **Manual Save를 따로** 둔다. 설계는 섬세해야 하므로 지금 하지 않는다.

복원 방식 후보 둘:

| 방식 | 내용 | 장단 |
|---|---|---|
| A. `StageState` 복원 | 저장 시점의 무대를 `StageState`로 굽고(굽는 쪽은 있음 — `StageReducer`·`StageStateCapture`) 로드 때 되살린다(되살리는 쪽 없음) | 즉시 복원. 되살리기 구현이 필요하고, 무대 밖 상태(대화 상자·샷·진행 중 트윈)까지 정의해야 한다 |
| B. 루트부터 달리기 | 장면 루트에서 저장 지점까지 시크로 재실행(롤백 리플레이와 같은 기전). 장면 안 진행 선택·Yarn 인라인 선택 경로를 세이브에 실어야 한다 | 구현이 지금 기전의 연장. 장면이 길면 시간이 걸리고 연출이 압축 재생되며 잠깐 보일 수 있다 — **로드 화면 뒤에서만 쓰면 무관**하다고 판단 |

소유자 판단(2026-09-02): 제한된 save/load 전용이라면 B의 단점은 로딩 화면이 가린다. 어느 쪽이든
자동(장면 경계) 세이브와 수동 세이브는 별개 슬롯·별개 뜻으로 두고, 자동 세이브의 "장면 진입
스냅샷" 정의는 바꾸지 않는다.
