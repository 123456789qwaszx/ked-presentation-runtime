# 이모지의 형식 — `emojis.json` (`emojis/2`)

| | |
|---|---|
| 무엇 | 이모지 하나가 툴에서 런타임으로 나가는 모양 — 구성과 움직임이 한 덩어리다. 이모지가 무엇인가는 [emoji-rig.md](emoji-rig.md), 순서는 [PLAN_emoji.md](PLAN_emoji.md) |
| 결정 | 아미야(소유자) 2026-11-11: 이모지 전용의 파일을 따로 둔다(`motions.json`에 얹지 않는다) · 그림 바꾸기는 계단 키 · 구간은 따로 선 클립이다 · 머묾이 있는가가 종류를 정한다 |
| 규범 | 읽는 코드 한 곳 — 코어의 `EmojisFileDto` · `EmojiDefinitionLoader` · `EmojiRules`. 런타임과 툴이 같은 것을 쓴다 |

## 0. 한 문장

> 이모지 하나 = **구성**(오프셋 + 리그들) + **클립들** + **어느 클립을 언제 재생하는가**. 시각은 프레임이다.

## 1. 파일

```json
{
  "schema": "emojis/2",
  "fps": 24,
  "emojis": [
    { "name": "star", "offset": { "x": 170, "y": 60 },
      "rigs": [ { "name": "body", "sprite": "star", "place": { "x": 0, "y": 0 }, "scale": 0.45 } ],
      "clips": [
        { "name": "in", "length": 5, "tracks": [
            { "rig": "body", "channel": "scaleX", "keys": [ { "f": 0, "v": 0.45 }, { "f": 3, "v": 1.27 }, { "f": 4, "v": 1 } ] },
            { "rig": "body", "channel": "alpha",  "keys": [ { "f": 0, "v": 0 }, { "f": 2, "v": 1 } ] } ] },
        { "name": "hold", "length": 16, "tracks": [ … ] },
        { "name": "out",  "length": 6,  "tracks": [ { "rig": "", "channel": "alpha", "keys": [ { "f": 0, "v": 1 }, { "f": 5, "v": 0 } ] } ] }
      ],
      "in": "in", "hold": "hold", "out": "out" }
  ]
}
```

| 필드 | 뜻 |
|---|---|
| `schema` | `emojis/2`. `emojis/1`(클립이 없는 최소형)도 그대로 읽힌다 |
| `fps` | 초당 프레임 수 — 프레임을 시간으로 바꾼다. 없으면 24 |
| `emojis[].name` | 대본이 부르는 이름(`<<emoji 누구 이름>>`) |
| `emojis[].offset` | 이모지별 오프셋(`Emoji_Offset`) — 로케이터 기준 px, y 위. 없으면 0 |
| `emojis[].fixedSide` | 참이면 인물의 방향을 따르지 않는다(§6). 없으면 거짓 — 따른다 |
| `emojis[].rigs[]` | 리그들 — 순서가 그려지는 순서다(뒤가 위). `name`은 툴이 붙인 이름, `sprite`는 기본 스프라이트(`Resources/Emojis/{키}`), `place` · `scale` · `rotation`은 기본 자리 · 배율 · 회전(`EmojiRig_Place` — 배율은 없으면 1, 회전은 도이고 없으면 0), `upright`는 뒤집히면 안 되는 그림의 표시(§6 — 없으면 거짓) |
| `emojis[].clips[]` | 클립들(§2) |
| `emojis[].main` · `in` · `hold` · `out` | 어느 클립을 언제 재생하는가 — 클립의 이름(§4) |

## 2. 클립 — 따로 선 애니메이션

툴에서는 타임라인 하나로 잡는다. 내보낼 때 구간마다 **따로 선 클립**으로 나간다 — 0~12fr 구간은 프레임 0에서 시작하는 13프레임짜리 클립이고, 8~14fr 구간은 7프레임짜리 클립이다. 구간이 겹쳐도 된다(각자 자기 프레임을 가져간다).

| 필드 | 뜻 |
|---|---|
| `name` | 클립의 이름. 한 이모지 안에서 겹치지 않는다 |
| `length` | 프레임 수 — 프레임 `0 … length-1`이 있다. 되풀이의 주기가 `length`다(마지막 프레임도 한 프레임만큼 보인다) |
| `tracks[]` | 대상 하나의 채널 하나 |
| `tracks[].rig` | 대상 — 리그의 이름. **빈 이름은 이모지 전체**(`Emoji_Offset`) |
| `tracks[].channel` | `x` · `y` · `scaleX` · `scaleY` · `rotation` · `alpha` · `sprite` |
| `tracks[].keys[]` | 키 — 프레임 오름차순, `0 … length-1` 안 |

## 3. 채널과 키

| 채널 | 값 | 중립(키가 없을 때) | 쓰는 곳 |
|---|---|---|---|
| `x` · `y` | px, y 위 | 0 | 리그는 `EmojiRig_Image`의 자리(기본 자리 `EmojiRig_Place` 기준). **이모지 전체는 오프셋 값에 더한다** |
| `scaleX` · `scaleY` | 배율 | 1 | 리그 · 이모지 전체 |
| `rotation` | 도(z) | 0 | 리그 · 이모지 전체 |
| `alpha` | 0~1 | 1 | 리그 · 이모지 전체(`CanvasGroup`) |
| `sprite` | 스프라이트 키 | 리그의 기본 스프라이트 | 리그만 |

**수치 키** `{ "f", "v", "i", "o", "step" }`

- `f` 프레임 · `v` 값.
- `i` · `o` — 들어오는 · 나가는 기울기(**프레임당**). 생략하면 0 — 키에서 평평하다(키 사이가 부드럽게 이어진다).
- `step: true` — **계단 키.** 다음 키까지 이 값으로 멈춰 있다.
- 키 사이는 3차 Hermite 곡선이다(코어 `CurveFunctions` — Unity `AnimationCurve`와 같은 값). 첫 키 앞과 마지막 키 뒤는 끝값이다.

**그림 키** `{ "f", "s" }` — 그 프레임부터 스프라이트 `s`다. 언제나 계단이다. 첫 키 앞은 리그의 기본 스프라이트다.

**키가 없는 채널은 중립값이다 — 앞 클립의 값을 이어받지 않는다.** 클립은 따로 선 애니메이션이다.

**키는 리그의 기본값 위에서 잡는다.** 그림을 0.45배로 쓰는 리그는 `scale: 0.45`를 한 번 적고, 키의 배율은 1을 기준으로 한다(등장이 `1.27 → 1`로 읽힌다). 기본 자리 · 배율 · 회전은 `EmojiRig_Place`에, 키는 그 밑의 `EmojiRig_Image`에 들어간다 — 클립마다 크기를 다시 적지 않는다.

## 4. 어느 클립을 언제 — 머묾이 있는가

| | 재생 | 건너뛰면 | 내리기 |
|---|---|---|---|
| **머묾이 없다**(`main`만) | `main`을 한 번 재생하고 **스스로 사라진다** | 세우지 않는다(남는 것이 없다) | 내릴 것이 아니다 — `emoji_off 이름`은 경고한다 |
| **머묾이 있다**(`hold`, 그리고 `in` · `out`은 있어도 없어도) | `in`을 한 번 → `hold`를 되풀이 | `hold`의 프레임 0으로 선다 | `emoji_off` → `out`을 한 번 재생하고 사라진다(`out`이 없으면 바로) |
| **클립이 없다** | 정의의 모습 그대로 서 있다 | 서 있다 | `emoji_off` → 바로 사라진다 |

- 멈춰서 남는 이모지는 **한 프레임짜리 `hold`**다.
- "하나로 이어진 애니메이션"은 `main` 하나다 — 끝에 남기려면 마지막 모습을 `hold`로 둔다.
- 등장이 끝나면 머묾의 프레임 0에서 잇는다. **등장 도중에 내리면 바로 퇴장으로 넘어간다.**
- 재생은 줄을 넘어 이어진다 — 다음 줄로 넘어가도 끝까지 간다.

규칙(어긋나면 그 이모지를 읽지 않는다): `main`과 `hold`를 함께 두지 않는다 · `in` · `out`은 `hold`가 있을 때만 · 클립이 있으면 `main`이나 `hold`가 있어야 한다 · 트랙의 리그는 그 이모지의 리그여야 한다 · 같은 대상의 같은 채널은 트랙 하나 · `sprite`는 리그에만.

## 5. 같은 계산

- 그 프레임의 모습: 코어 `EmojiClipMath.SampleNode(클립, 대상, 프레임)`.
- 지금 어느 클립의 몇 프레임인가: 코어 `EmojiPlayback`(시간을 넘기는 것과 내리는 것만 받는 상태 기계).
- 런타임(`EmojiPlaybackSystem`)은 시간을 넘기고 값을 노드에 옮기기만 한다. 툴의 미리보기가 같은 둘을 쓴다.

## 6. 좌우 — `fixedSide` · `upright`

**이모지는 오른쪽을 보는(뒤집히지 않은) 인물을 기준으로 만든다.** `offset` · `place` · x 키 · 회전을 그 기준으로 적는다. 인물이 뒤집혀 있으면(`mirror` — 왼쪽을 본다) 런타임이 `Emoji_Locator`를 뒤집어 이모지를 **통째로 거울에 비춘다** — 파일의 값은 하나도 바뀌지 않는다. 서 있는 동안 인물이 뒤집히면 따라 뒤집힌다.

예외는 둘이고, 둘 다 참/거짓 하나다(없으면 거짓).

| 칸 | 어디 | 뜻 | 쓰는 곳 |
|---|---|---|---|
| `fixedSide` | 이모지 | 인물의 방향을 따르지 않는다 — 인물이 뒤집혀도 만든 쪽 그대로 선다. 로케이터의 자리(머리가 어디인가)는 인물을 따라간다 | 머리 위 한가운데에 뜨는 것, 화면 기준으로 흐르는 것 |
| `upright` | 리그 | 뒤집히면 안 되는 그림. 이모지가 거울에 비칠 때 이 리그의 **그림과 키는 만든 그대로** 보이고, **기본 자리만** 거울 쪽으로 간다 | 물음표 · 느낌표 · 글자 |

- `upright` 리그가 바깥으로 흐르는 x 키를 가졌다면 뒤집힌 인물에서는 안쪽으로 흐른다(키가 만든 그대로 보이므로). 그런 움직임은 이모지 전체의 키(`rig: ""`)로 잡는다 — 그것은 뒤집힌다.
- `fixedSide` 이모지 안의 `upright`는 뜻이 없다(거울에 비치지 않는다).
- 좌우 대칭인 이모지는 두 칸이 없어도 같다.

**같은 계산** — 누가 한 번 더 뒤집는가는 코어 `EmojiSide`(`OffsetSign` · `PlaceSign`)가 낸다. 부호가 −1인 `Emoji_Offset`은 자리의 x · 가로 배율 · 회전에, `EmojiRig_Place`는 가로 배율 · 회전에 그 부호를 곱한다. 툴의 "왼쪽을 보는 인물로 보기"가 같은 것을 쓴다.
