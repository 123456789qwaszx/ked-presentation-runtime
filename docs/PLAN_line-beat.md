# 대사 줄의 자리 — 표지와 `at`, 줄에는 시간이 없다 (2026-11-17)

> 상태: **런타임 끝(L1–L3 · L5)** — 소유자가 방향과 §2, §11(추천대로)을 정했다(2026-11-17). L4는 작업공간이 끝냈고, 남은 소비처(추출기 · 저작 툴 · 모션 툴의 코어 사본)는 [stage-changes-handoff.md](stage-changes-handoff.md)를 따른다.
> 출발: ked-vn-workspace 세션의 제안 "인라인 명령 — 자리와 명령을 가른다"(2026-11-17, 기준 `f215092d`). 소유자: "런타임 쪽에서 이런 방향으로 바꾸는 게 필요하다."
> 앞선 계획: [PLAN_stage-step-inline-markup.md](PLAN_stage-step-inline-markup.md)(무대 스텝 `<<step>>` · 인라인 `[cmd]`) — 이 계획이 그 인라인 부분을 대신한다. 무대 스텝은 그대로다.

## 1. 왜

### 1.1 번역 — 명령이 대사 글 안에 있다

Yarn은 `<<명령>>`을 언어별 문자열 표에 넣지 않고 **줄 글(마크업 포함)만** 언어마다 가져온다. 지금의 인라인 `[cmd="face_swap s2 03 0.3s"/]`는 줄 글 안이라 번역 파일에 실린다.

| # | 문제 | 까닭 |
|---|---|---|
| 1 | 번역자가 연출 명령을 들고 옮긴다 — 슬롯 · 표정 번호 · 길이가 번역 파일에 드러나고, 따옴표 하나가 깨지면 그 언어에서만 연출이 빠진다 | 명령 글이 대사 글 안에 있다 |
| 2 | 연출을 고치면 모든 언어의 글을 고친다 | 명령이 언어마다 복사돼 있다 |
| 3 | 언어마다 연출이 갈라진다 | 번역자가 빠뜨리거나 바꾼 마커가 그 언어의 연출이 된다 |
| 4 | 폴드와 재생이 어긋난다 | 폴드는 원문 `.yarn`의 `[cmd]`를(`YarnCommandTextExtractor.StripInlineCommands`), 재생은 그 언어 줄 글의 `[cmd]`를(`InlineCommandTrack.Begin`) 센다 |

### 1.2 순서 — 시간과 글이 한 줄에서 경주한다

줄 머리의 `pause`는 **시각** 자리(줄이 들어온 뒤 N초)이고 인라인은 **글자** 자리다. 한 줄에 둘이 있으면 경주한다 — 지금 `[cmd]`에도 있는 문제다.

```
<<face s1 01>> <<pause 1s>> <<face s1 02>>        머리
세이나: [cmd="face s1 03"/]아, 음……                 첫 글자의 인라인

재생: 0초 01 → 첫 글자(0.2초) 03 → 1초 02   끝 표정 02
폴드: 머리(01 · 02) → 인라인(03)             끝 표정 03
```

## 2. 정한 것 (소유자, 2026-11-17)

| | 결정 |
|---|---|
| D1 | **자리와 명령을 가른다.** 글에는 자리 표지 `[beat=이름/]`만, 명령은 줄 앞의 명령 줄 `<<at 이름 명령 한 줄>>`. 자리는 언어마다, 명령은 모든 언어에 하나 |
| D2 | **`at`이 없는 명령은 줄 머리 — 대사와 함께 시작한다.** 지금 그대로다. `start` 같은 예약 이름은 두지 않는다 |
| D3 | **대사 줄에는 시간이 없다.** 줄 머리에서 기다리는 명령(`pause` · 덮기 `screen_cover`)을 금지한다. 시간으로 짜는 일(덮인 채 머물기 · 나가고 들어오기 · 머리의 짧은 효과)은 무대 스텝(`<<step>>`)에서 한다 |
| D4 | **`<<Nfr>>` 별칭을 걷는다.** `<<pause 12fr>>`와 같은 뜻이다(작업공간 0곳, 런타임 3곳) |
| D5 | **자동 줄의 머무름은 줄 태그 값으로** — `#place #auto=1.8s`. 지금은 줄 머리의 마지막 `pause`가 이 일을 흉내 낸다(작업공간 60곳 — 장소 카드 41 · 장제목 18 · 도입 1, 0.27~4.47초) |
| D6 | **`[cmd]`는 이행 뒤 걷는다.** 둘이 있으면 §1.1의 길이 열려 있다 |
| D7 | 작업공간 대본의 줄 머리는 작업공간이 바꾼다(도구가 다시 낸다) |

## 3. 한 스텝의 시간표

**대사 줄 — 글 자리뿐**

```
줄이 들어온다
 ├ 머리      at 없는 명령 — 쓴 순서대로 함께 시작한다. 기다리지 않는다(D3)
 ├ 대사창이 열리고 타자기가 시작된다
 ├ 표지      [beat=a/]의 글자가 드러나기 직전 — <<at a …>>(쓴 순서)
 ├ end       타자기 끝 — <<at end …>>와 그때까지 남은 것
 └ 넘김      입력(또는 #auto — 머무름이 지나고 글이 다 보이면)
```

**무대 스텝(`<<step>>`) — 시간으로 짠다** (지금 그대로)

```
쌓인 명령을 쓴 순서대로 — pause · screen_cover가 기다린다. 기다림이 끝나면 Yarn이 다음으로 간다
```

| 자리 | 쓰는 법 | 언제 | 기다리는 명령 |
|---|---|---|---|
| 머리 | `<<명령>>` | 줄이 들어올 때 대사와 함께 | 금지(D3) |
| 표지 | `<<at a 명령>>` + 글의 `[beat=a/]` | 그 글자가 드러나기 직전 | 금지 |
| 끝 | `<<at end 명령>>` | 타자기가 끝날 때 | 금지 |
| 무대 스텝 | `<<명령>>` … `<<step>>` | 쓴 순서, 기다림대로 | 된다 |

- 머리와 "첫 글자의 표지"는 다르다 — 머리는 대사창이 열리기 **전**, 표지는 첫 글자가 **보일 때**다.
- 전경을 뺀 어휘는 모두 `at` 안에 쓸 수 있다(지금 `[cmd]`에 쓸 수 있는 것과 같다).

## 4. 어휘와 규칙

```yarn
<<face s2 05>>                          머리 — 대사와 함께
<<at a face_swap s2 03 0.3s>>           표지 a
<<at a motion s2 a008_s2>>              같은 이름은 쓴 순서
<<at end emoji s2 sweat>>               타자기 끝
세이나: 아, 음…… [beat=a/]이건 비밀인데.

09:15|운월|30일|필리에 온실 구역|풍요의 광장 #place #auto=1.8s
```

| # | 경우 | 규칙 |
|---|---|---|
| R1 | `<<at>>`가 붙는 줄 | 바로 다음 **대사 줄**. 다음이 `<<step>>` · 선택지(`->`) · 노드 끝이면 원문 검사의 오류. 실행 중 만나면 경고하고 그 스텝의 머리 **뒤**에 붙인다(사라지지 않게, 앞서지 않게). 선택지는 스텝이 아니라 실행 중에는 고른 뒤의 대사 줄로 간다(표지가 없으면 R5) |
| R2 | 한 줄 안의 순서 | 머리(쓴 순서) → 표지(글자 자리 → 같은 자리면 원문 표지 순서 → 같은 이름이면 `<<at>>` 쓴 순서) → `end`. 안정 정렬 |
| R3 | 폴드 | 줄 그룹에서 머리 명령(쓴 순서) **뒤에** at 명령을 원문 표지 순서로, 마지막에 `end`. `<<at>>`를 쓴 자리에서 접지 않는다(머리 명령보다 앞서 접혀 재생과 어긋난다) |
| R4 | 번역문 | 표지의 **집합과 순서**가 원문과 같아야 한다 — 같은 인물의 같은 축을 a → b로 두 번 바꾸는 줄에서 순서가 뒤집히면 끝 상태가 달라진다. 검사는 번역 검사 도구가 한다(§10) |
| R5 | 번역문에 표지가 없음 | 그 명령은 줄 끝(`end` 자리)에서 실행하고 경고한다 — 연출이 사라지지 않게 |
| R6 | 원문의 표지 짝 | 표지에 `<<at>>`가 없으면 경고하고 무시. `<<at>>`에 표지가 없거나 같은 표지가 둘이면 오류 |
| R7 | 표지 이름 | 그 줄 안에서만 유일. 꼴은 영문 소문자 · 숫자. `end`는 예약 |
| R8 | 기다리는 명령 | 줄 머리 · 표지 · `end` 어디에도 못 쓴다(D3). 무대 스텝에서만 |
| R9 | `#auto=길이` | 줄이 들어온 때부터 그 길이가 지나고 글이 다 보이면 넘긴다. 값이 없으면 지금처럼 다 보이면 바로. 길이 표기는 `pause`와 같다(`1.8s` · `54fr`), 시계도 `pause`와 같은 실시간이다(`WaitCommand` — 속도 올리기와 상관없다). 표기를 읽는 곳은 코어 `AutoAdvanceTag`(툴도 같은 것을 쓴다) |

## 5. 되감기 · 압축 · 순서 — 무엇을 지키나

### 5.1 지금 이미 지키는 것(코드로 확인)

| 장치 | 하는 일 |
|---|---|
| 넘김 문(`AdvanceGate.IsForegroundBusy`) | 그 스텝의 명령이 도는 동안 다음 줄을 열지 않는다 — 사용자 · 자동 · 빨리 넘기기 모두. 덧붙은 실행(인라인)도 같은 스텝으로 센다 |
| 스텝 경계(`CommandExecutor.PlaySpecs`) | 앞 스텝의 배경 명령을 끝값으로 마무리한다(`CleanupStep(Finish)`) |
| 정지(되감기 · 이어하기의 시작) | 실행 세대(`runId`)를 올려 코루틴을 끊고, 마스크 · 어둡기 판 · 틀 · 화면 효과 · 샷 · 블러를 기준으로, 리그를 치운 뒤 루트부터 압축으로 다시 접는다. 끊긴 줄의 남은 인라인은 실행하지 않는다 |
| 시크 통과 줄(`RunSeekPassThrough`) | 머리 압축 → 인라인 전부 글 순서로 압축 |

### 5.2 지킬 것 — 무엇이 지키나

새로 더한 장치는 at 대기열(I1)과 순서 함수(I3) 둘뿐이다. 나머지는 §5.1의 장치가 이미 지킨다.

| | 지킬 것 | 무엇이 지키나 |
|---|---|---|
| I1 소속 | at 명령은 정확히 한 줄에 속한다 | **새로** — 실행기(`YarnPlaybackDriver`)가 at을 머리 배치와 따로 모은다. 줄에 들어갈 때 `InlineCommandTrack.Begin`이 가져가고, 무대 스텝이면 그 머리 뒤에(R1), 정지면 쌓인 명령과 함께 버린다(`TryDiscardPending`) |
| I2 한 번 | 각 명령은 많아야 한 번 실행된다 | 지금 그대로 — 줄의 목록 하나와 앞으로만 가는 커서 하나. 타자기(`PlayUpTo`) · 줄 끝(`PlayRemaining`) · 시크가 같은 커서를 지난다 |
| I3 순서 | 재생 순서 = 폴드 순서(머리 → 표지 → `end`) | **새로** — 순서를 정하는 함수가 하나다(코어 `LineBeatSchedule`, 재생과 폴드가 같이 부른다). 시간과 글의 경주는 D3이 없앤다(L3) |
| I4 경계 | 다음 스텝의 머리 전에 앞 줄의 at은 모두 "실행됨" 또는 "버려짐"이다 | 지금 그대로 — 줄 끝(`PlayRemaining`)은 넘김을 기다리기 **전**에 돌고, 다음 머리에 닿는 길은 넘김뿐이다. 끊긴 줄은 실행하지 않고 다음 `Begin`이 지운다 |
| I5 세대 | 끊긴 줄의 명령 · 콜백은 새 장면에 닿지 않는다 | 지금 그대로 — 실행기가 지난 세대의 스코프를 받지 않는다(`CommandExecutor.PlaySpecsInStep`). 정지는 진행 중인 줄 처리가 빠져나오기를 기다린 뒤 새 대화를 연다(`CustomLinePresenter`의 배수 통로). 늦은 글자 콜백은 타자기의 실행 번호가 막는다(`EllipsisBreathTypewriter`) |
| I6 트윈 | 늦게 끝나는 전환이 새 상태를 덮지 않는다 | 지금 그대로 — 전환은 명령이 아니라 컨트롤러가 갖는다(command-authoring.md §3). 정지에서 기준으로 Snap/Kill, 스텝 경계에서 배경 명령은 끝값으로 |

- 처음 구현(L2 첫 커밋)은 I4 · I5에 검사를 더했다 — 줄마다 따로 만든 목록 · 실행 세대 비교 · 다음 머리의 닫힘 검사. 위 장치와 겹치고, 닫힘 검사는 "늦게라도 실행"하는 길을 스스로 만들어 걷었다(소유자 지적, 2026-11-17).

### 5.3 재생 방식마다

| 상황 | 머리 | 표지 · `end` | 넘김 · `#auto=` |
|---|---|---|---|
| 보통 재생 | 대사와 함께 시작 | 그 글자가 보일 때 · 타자기 끝 | 입력. `#auto=1.8s`는 1.8초와 글 끝 중 늦은 때 |
| 글 서두르기(첫 클릭) | 그대로 | 타자기가 빨리 돌며 차례로 | 같다 |
| 머무는 `#auto` 줄에서 클릭 | — | — | 머무름을 건너뛰고 넘긴다(지금 `pause` 중 클릭과 같다) |
| 빨리 넘기기(Ctrl) | 압축 | 전부 압축으로 순서대로 | 머무름 없이 |
| 시크 통과(되감기 · 이어하기의 앞 줄들) | 압축 | 타자기 없이 전부 압축으로 순서대로 | 머무름 없이 |
| 되감기로 닿은 줄 | 보통 재생과 같다 | 같다 | `#auto` 줄도 넘기지 않는다 — 다시 보려고 돌아온 것이다(지금 그대로, `LineAdvancePolicy`) |
| 끊김(정지 · 되감기의 시작) | — | 남은 것은 버린다 — 정지가 기준으로 돌리고 루트부터 다시 접는다 | — |
| 무대 스텝 | 지금 그대로 — 기다림대로, 압축이면 한 프레임 | — | — |

## 10. 하지 않는 것

- 번역 파이프라인 전체(문자열 표 내보내기 · 번역 도구). 번역 검사(R4 · 표지 집합)는 그 도구가 한다 — 원문 표지 목록은 코어 추출기가 낸다.
- 음성 시각에 맞추기 — 나중에. 표지는 그대로 두고 그 시각만 음성에서 읽으면 된다.
- 작업공간의 "따온 조각"(AI가 쓰는 줄마다 연기 목록)은 바뀌지 않는다 — 옮기는 도구가 내는 꼴만 바뀐다. 자리는 원문(기본 언어)에 대한 것이다.
