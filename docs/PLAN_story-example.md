# 스토리 예제 — 폴더의 챕터를 카드로 골라 재생 (설계 · 구현, 2026-11-20)

| 결정 | 아미야(소유자) 2026-11-20: ① 기존 두 예제는 두고 **세 번째 예제**로 더한다 ② **폴더 하나를 지정**하면 그 안의 진행 JSON을 자동으로 모은다 ③ 챕터는 **서로 독립, 늘 처음부터** — 잠김 · 클리어 표시 없음 |

## 목표 한 문장

> 스토리 화면은 **폴더 하나의 챕터들**이다. 챕터 JSON 하나가 카드 한 장이고, 카드는 그 챕터를 처음부터 재생한다.

## 1. 쓰는 법

1. ked-story-director의 `exported/`(진행 JSON + `yarn/`)를 `Assets/Dialogue/` 아래 폴더 하나에 둔다. 툴의 [⚙ 설정] › 내보내기가 그 폴더로 복제하게 해 두면 저장할 때마다 들어온다.
   대사 Yarn은 Yarn 프로젝트(`Assets/Dialogue/YarnProject.yarnproject` — `**/*.yarn`)가 컴파일하므로 `Assets/Dialogue/` 아래여야 한다.
2. 씬의 `SampleBootstrap` › **Story Folder**에 그 폴더 경로를 적는다(기본 `Assets/Dialogue/Story`).
3. **예제**를 `Story`로 두거나, 타이틀의 [다른 예제로]를 스토리가 나올 때까지 누른다(진행·저장 → 연출 데모 → 스토리).
4. 타이틀의 [처음부터] → 챕터 카드 화면 → 카드를 누르면 그 챕터가 재생된다. 챕터가 끝나면 끝 카드의 [챕터 목록으로]가 카드 화면으로 돌아온다.

## 2. 구조

| 자리 | 무엇 |
|---|---|
| `SampleBootstrap` | 예제 `Story`. 에디터에서는 재생을 시작할 때마다 Story Folder(하위 폴더 포함)의 `*.progression.json`을 훑는다 — 갱신 단계가 없다. 빌드는 폴더를 훑지 못하므로 구워 둔 목록(Story Chapters — 컴포넌트 메뉴 `Story/폴더의 챕터를 목록에 굽기`)을 쓴다 |
| `ProgressionContentLoader.LoadChapters` | 챕터마다 따로 싣는다 — 깨진 챕터 · ID가 겹친 챕터는 소리 내고 **빼고** 나머지로 시나리오를 세운다(폴더에는 무엇이든 들어올 수 있다). 순서는 ChapterId(숫자는 수로) |
| `ProgressionLauncher.StartChapter` | 시나리오의 그 챕터를 새 회차로. 스탯은 그 챕터의 초기값부터 |
| `StoryPanel` · `StoryChapterCard` (화면 묶음 `Screens/Story`) | 가로 ScrollRect에 카드 견본을 챕터 수만큼 복제한다. 진행 코어를 모른다 — 번호 · 이름 · 한 줄 정보만 받는다 |
| `KedUIFlow.Story` | 시나리오 → 카드, 카드 → `StartChapter`, 챕터 끝 → 카드 화면으로 |

세울 챕터가 하나도 없으면(폴더가 비었거나 전부 깨짐) 오류를 내고 **진행·저장 예제로 연다** — [다른 예제로]로 들어왔을 때 빈 화면에 갇히지 않게.

## 3. 저장

저장 폴더는 `saves-story`로 따로다. 회차 · 장면 경계 저장 · 수동 슬롯 · 백로그는 다른 예제와 같다 — 타이틀의 [이어하기]는 마지막으로 하던 챕터를 잇는다.
카드를 누르면 언제나 새 회차다(하던 회차는 수동 슬롯에 남긴 것만 남는다).

## 4. 하지 않은 것

- 잠김 · 클리어 · 챕터 간 스탯 이월 — 결정 ③.
- 대사 Yarn이 프로젝트에 있는지의 사전 검사. 진행 JSON만 넣고 Yarn을 빼면 카드를 누른 뒤 Yarn이 노드를 못 찾는다.
- 폴더 여럿(스토리 여럿) — 지금은 폴더 하나가 스토리 하나다.
